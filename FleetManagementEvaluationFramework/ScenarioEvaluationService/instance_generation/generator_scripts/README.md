# generator_scripts:
* All content regarding routing graph genertaion is listed here.

## generation_system_state_file:
* All methods to generate system state files are placed here.

## image_to_graph_hexagonal:
* All methods to generate hexagonal grid routing graphs are placed here.

## image_to_graph_prm:
* All methods to generate probabilistic roadmaps (PRMs) graphs are placed here.

## image_to_graph_quadratic:
* All methods to generate quadratic grid routing graphs are placed here.

## image_to_graph_triangle:
* All methods to generate triangular grid routing graphs are placed here.

## image_to_task:
* All methods to generate task coordinates from images are placed here.

## mapf_scenario_generation:
* All methods to generate MAPF scenarios are placed here.

## network_x_to_lif:
* Method to transform networkx graph to the Layout Interchange Format (LIF).

## odrm_graph_to_udrm_graph:
* Method to transform Optimized Directed Roadmap Graph (ODRM) to Undirected Roadmap Graph (UDRM).

## order_scenario_generation:
* Methods to generate order files are placed here.

## prm_graph_to_odrm_graph:
* Methods to compute an Optimized Directed Roadmap Graph (ODRM) without gray endpoints areas are placed here.

## prm_graph_to_odrm_graph_with_fix_endpoints:
* Methods to compute an Optimized Directed Roadmap Graph (ODRM) with gray endpoints areas are placed here.
