# interfaces
All content regarding interfaces is placed here.

## collision_detection_interface:
* Defines an interface for collision detection used in multi-agent path planning to avoid collisions.

## low_level_search_interface:
* Defines an interface for the low-level search in multi-agent path planning, e.g. A Star, or Interval A Star

## path_planning_heuristic_interface:
* Defines an interface for the heuristic used in path planning, e.g. in A Star, like Manhattan or Euclidean distance.

## path_planning_interface:
* Defines an interface for the path planning method.
