# api
All content regarding the restful api and the mqtt is placed here.

## api_config:
- Contains all content regarding the definition of fast api and fast mqtt for this microservice.

## client_api:
- Defines the client api calls.

## client_api_models:
- defines all data models for publishing outgoing mqtt-messages

## server_api_models:
- defines all data models for subscription of incoming mqtt-messages

## serialization:
- contains a method for serialize objects to json
