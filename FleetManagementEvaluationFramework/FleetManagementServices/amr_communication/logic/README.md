# logic
All content regarding calculation of logical processes is placed here.

## amr_state_update_functions:
- defines all methods that are directly associated with the processing of the state update from the amr.

## general_functions:
- defines general help functions.

## service:
- defines all methods that are directly associated with the expected service of a server request.

## transformation_functions:
- defines all methods that are directly associated with the transformation of data from one format to another.
