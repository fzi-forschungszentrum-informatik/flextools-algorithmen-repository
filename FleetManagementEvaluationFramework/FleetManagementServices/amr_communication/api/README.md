# api
All content regarding the restful api is placed here.

## api_config:
- host: defines the host-address under which the amrcommunication-service is available.
- port: defines port under which the amrcommunication-service is available.
- allowed_origins: defines the host-addresses, that are allowed to communicate with the amrcommunication-service.
- fast-mqtt broker config
- defines the subscription and publish function of the mqtt broker.

## server_api_models:
- defines the data models for the incoming server api requests.

## client_api_models:
- defines the data models for the outgoing client api calls.

## server_api:
- defines the response for incoming server api requests. 

## client_api:
- defines the outgoing client api calls.

## serialization:
- contains a method for serialize objects to json.
